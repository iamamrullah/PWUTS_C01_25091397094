# UTS Pemrograman Web

# Arjuno RentCar

## Deskripsi Proyek

Arjuno RentCar merupakan website simulasi penyewaan mobil yang dibuat untuk memenuhi Ujian Tengah Semester (UTS) mata kuliah Pemrograman Web. Website ini menggunakan HTML, CSS, JavaScript, jQuery, dan AJAX.

## Implementasi Tugas

1. **Homepage (`index.html`)**  
   Menyediakan halaman utama yang responsif, navigasi, daftar kendaraan, informasi harga sewa, dan status ketersediaan mobil. Tampilan disesuaikan untuk perangkat desktop maupun seluler menggunakan HTML dan CSS.

2. **Halaman Detail Mobil (`pages/detail.html`)**  
   Menampilkan informasi kendaraan yang dipilih, harga sewa, waktu mulai, durasi sewa, perkiraan waktu selesai, dan total biaya. JavaScript/jQuery digunakan untuk menghitung biaya serta memvalidasi input penyewaan.

3. **Halaman Pembayaran (`pages/payment.html`)**  
   Menyediakan formulir data penyewa, ringkasan transaksi, informasi rekening, unggah bukti pembayaran, dan persetujuan ketentuan. Validasi dilakukan menggunakan JavaScript/jQuery sebelum simulasi transaksi diselesaikan.

4. **Navigasi dan AJAX**  
   Halaman detail mobil dan pembayaran dimuat melalui AJAX ke dalam layout utama, sehingga pengguna dapat berpindah halaman tanpa membuka dokumen HTML utama yang berbeda secara langsung.

5. **Simulasi Transaksi**  
   Website mendukung pemilihan kendaraan, perhitungan biaya sewa, validasi formulir, pratinjau bukti pembayaran, serta pembuatan kode booking simulasi. Fitur transaksi belum terhubung ke server atau basis data.

## Catatan

Seluruh data kendaraan dan rekening yang digunakan merupakan data demonstrasi. Website ini dibuat sebagai implementasi frontend untuk kebutuhan UTS.
